# 🎨 Art Portfolio

A minimalist, animated portfolio site to showcase personal artwork and design projects. Built as a creative expression of both front-end design and visual storytelling.

![Art Portfolio Preview](https://raw.githubusercontent.com/sarahgraup/artsite/main/public/preview.png)

## 🌐 Live Demo
[View Live Site](https://artsite-chi.vercel.app)

## ✨ Features
- **Responsive Design**: Seamlessly adapts to all device sizes
- **Animated UI**: Smooth transitions and interactive elements
- **Dynamic Gallery**: Showcases artwork with elegant hover effects
- **Color Scheme**: Thoughtfully designed color palette to complement artwork
- **Optimized Performance**: Fast load times and smooth interactions

## Tech Stack
- Next.js
- Tailwind CSS

## 📁 Project Structure
```
artsite/
├── components/        # Reusable UI components
├── pages/             # Application pages
├── public/            # Static assets
├── styles/            # Global styles
└── utils/             # Helper functions
```

## 🚀 Getting Started

### Installation

1. Clone the repository:
```bash
git clone https://github.com/sarahgraup/artsite.git
```

2. Navigate to the project directory:
```bash
cd artsite
```

3. Install dependencies:
```bash
npm install
# or
yarn install
```

4. Start the development server:
```bash
npm run dev
# or
yarn dev
```

5. Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.

## 📱 Usage
- Browse through the gallery of artwork
- Click on individual pieces to view details
- Navigate through the portfolio using the intuitive UI
